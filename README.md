# УрФУ · Свой маршрут

Конкурсный прототип сайта университета. **Не официальный сайт УрФУ.**

Сайт помогает найти следующий шаг: поступление, программы, учебные сервисы, кампус и контакты. Стек — HTML, CSS, чистый JavaScript. Сборка и npm для просмотра не нужны. Все изображения, шрифты и данные находятся в репозитории.

## Открыть

- Скачайте весь репозиторий и откройте `index.html` двойным щелчком. Сохраняйте структуру папок.
- Либо из корня проекта: `python scripts/serve.py --port 4173` (со сжатием) или `python -m http.server 4173`. Откройте локальный сервер в браузере.
- Для GitHub Pages: опубликуйте корень ветки, в которой находятся эти файлы. `.nojekyll` уже добавлен. Публичный сайт в рамках текущей работы ещё не опубликован.

При `file://` работают обычные скрипты и локальные данные, без `fetch` и JS-модулей. Service worker доступен только на HTTPS и localhost. Хранение настроек и копирование ссылок зависят от разрешений браузера; отсутствие localStorage не останавливает интерфейс. Управляемый Chromium облачной среды запрещает переходы `file://`, поэтому прямое открытие файла нужно дополнительно проверить на обычном компьютере.

## Что попробовать

1. Смените роль на главной. Откройте каталог и укажите предметы ЕГЭ.
2. Выберите до трёх программ для сравнения. Фильтры и сравнение сохраняются в адресе.
3. Найдите «общага», «стипуха» или «пары» через поиск.
4. Откройте `room.html?room=Р-237` — подтверждённый адрес корпуса без выдуманного этажа.
5. Посмотрите демо-расписание группы `РИ-140944`, переключите день и скачайте `.ics`.
6. Отметьте документы в чек-листе поселения. Измените настройки доступности и тему.

## Данные и честные ограничения

Снимок официального каталога от **25 октября 2026 года**, набор **2026**, очный бакалавриат и специалитет: **101 программа**. Английские названия подтверждены для **82 программ**. Источники указаны в данных и на страницах. Новые уровни образования не смешиваются с выбранными ступенями и доступны по ссылке в официальный каталог.

Проходные баллы в собранном каталоге не опубликованы. Калькулятор сравнивает сумму с суммой минимумов, не прогнозирует бюджет и предупреждает о проверке каждого экзамена. Нет подтверждённых календаря приёма 2027 года, тарифов общежитий, схем этажей и будущей афиши. Неизвестные значения не подменяются примерами. Расписание и кабинет явно помечены как демо.

Полный ручной аудит WCAG 2.2 AA и публикация ещё не завершены. Локальные результаты проверок лежат в `docs/`; они не являются отчётом Google PageSpeed Insights опубликованного сайта.

## Обновить данные

Для просмотра не нужны зависимости. Для повторного сбора нужны Python и `lxml`:

```sh
python scripts/collect.py
python scripts/enrich.py
python scripts/prepare.py
```

`collect.py` скачивает только официальные страницы каталога, `enrich.py` добавляет подтверждённые английские названия. `prepare.py` разделяет данные по страницам и обновляет готовые HTML и офлайн-манифест. Исходный снимок — `data/catalogue.json`; рабочие файлы браузера — `data/*.js`, без запросов к JSON. `scripts/build.py` использует стандартную библиотеку Python и пересобирает только HTML; для обычного просмотра запускать его не нужно.

## Локальная проверка

`python scripts/browser_check.py` — проверка пользовательских сценариев и ширин 320–2560 px при запущенном сервере. Для неё нужны Python Playwright и Chromium. Зависимости тестовых инструментов не входят в сайт.

Материалы: `concept.html`, `style.html`, `docs/assets.md`. PDF на 18 страниц — `docs/urfu-design-project.pdf`, ролик на 60 секунд — `docs/urfu-walkthrough-60s.mp4`. Видео показывает прототип и демо-данные, а не реальные учебные сервисы.
